### Needs Improvement

One area I need to improve is time management. In a project involving infrastructure work, I sometimes underestimated how long tasks such as provisioning resources, waiting for deployment propagation, and resolving environment issues would take. I should plan my schedule more carefully, break work into smaller milestones, and leave buffer time for unexpected delays so that progress stays steady and deadlines are met more reliably.
