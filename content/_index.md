### Project Summary

**BorrowIt** is a peer-to-peer rental platform — a React frontend with an Express
API and a PostgreSQL database, originally hosted on Supabase. Over this
internship it was migrated onto AWS, defined entirely as infrastructure-as-code
with the AWS CDK: Amazon RDS for the database, AWS Fargate behind an Application
Load Balancer for the API, and Amazon S3 with CloudFront for the web client and
user uploads.

The planning and design work behind that architecture is set out in
[section 2](2-Proposal/), and the migration itself is documented as a reproducible
workshop in [section 3](3-Workshop/), written so that a reader starting from an
empty AWS account can rebuild the whole environment.
